### Task 3: Fix clippy warnings — float precision and loop indexing

**Files:**
- Modify: files in `libs/rcad-kernel/src/`, `libs/rcad-algorithms/src/` with float precision and loop indexing warnings

This task handles the two largest categories: excessive float precision (32 errors) and loop variable indexing (16 errors).

- [ ] **Step 1: Fix excessive float precision**

```bash
cargo clippy --workspace --all-targets -- -D warnings 2>&1 | grep "excessive precision"
```

For each, truncate the float literal to `f64` precision (roughly 16 significant digits). For example:
- `3.14159265358979323846` → `3.141592653589793` (std::f64::consts::PI exists — use the constant if applicable)
- `1.00000000000000000` → `1.0`

- [ ] **Step 2: Fix loop variable indexing**

```bash
cargo clippy --workspace --all-targets -- -D warnings 2>&1 | grep "loop variable"
```

For "loop variable is only used to index": replace `for c in 0..d.len()` with `for item in d.iter()` (or `.iter_mut()`) and use `item` instead of `d[c]`.

For "loop variable is used to index": replace `for i in 0..knots.len()` with `for (i, knot) in knots.iter().enumerate()` and use `*knot` instead of `knots[i]`.

- [ ] **Step 3: Fix remaining clippy warnings**


- "manually copying between slices" (1) — use `dest.copy_from_slice(&src[range])` or equivalent
- Remaining collapsible ifs — follow clippy's suggestion output

### Task 4: Create the GitHub Actions workflow file

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Create the directory**

```bash
mkdir -p .github/workflows
```

- [ ] **Step 2: Write the workflow file**

Create `.github/workflows/ci.yml` with the following content:

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

env:
  CARGO_TERM_COLOR: always

jobs:
  lint:
    name: Lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt, clippy
      - uses: Swatinem/rust-cache@v2
      - name: Check formatting
        run: cargo fmt --all --check
      - name: Clippy
        run: cargo clippy --workspace --all-targets -- -D warnings

  test:
    name: Test (${{ matrix.os }})
    runs-on: ${{ matrix.os }}
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest]
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
      - name: Run tests
        run: cargo test --workspace

  wasm:
    name: WASM Build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: wasm32-unknown-unknown
      - uses: Swatinem/rust-cache@v2
      - uses: jetli/trunk-action@v0.5.0
      - name: Build creator-egui
        run: trunk build
        working-directory: apps/creator-egui
      - name: Build creator-iced
        run: trunk build
        working-directory: apps/creator-iced

  examples:
    name: Examples
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
      - name: Build examples
        run: cargo build --examples
```

- [ ] **Step 3: Validate YAML syntax**

```bash

```

Expected: "YAML valid"

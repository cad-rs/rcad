## 1. 概述

多物理场仿真（Multi-Physics Simulation）是指在同一个计算域内同时模拟多种物理现象（如结构力学、流体动力学、热传导、电磁场等）及其相互作用。这类仿真对CAD几何引擎提出了比传统设计用途更为严格的要求。

本文档调研多物理场仿真对CAD引擎的核心需求，并分析RCAD项目当前的能力差距，为后续功能规划提供参考。

### 多物理场仿真典型场景

| 仿真类型 | 涉及物理场 | 典型应用 |
|---------|-----------|---------|
| FEA/结构分析 | 固体力学、热力学 | 机械应力、热应力分析 |
| CFD | 流体动力学、热传导 | 气动外形、散热设计 |
| 电磁仿真 | 电磁场 | 天线设计、电机设计 |
| 热-流耦合 | 流体、热传导 | 电子散热 |
| 流-固耦合(FSI) | 流体、固体力学 | 气动弹性、心血管 |
| 热-结构耦合 | 热传导、固体力学 | 热应力分析 |
| 电磁-热耦合 | 电磁场、热传导 | 感应加热 |

## 2. 多物理场仿真背景

### 2.1 CAE工作流程

典型CAE前处理工作流程：

```
CAD模型导入 → 几何清理/简化 → 几何修复 → 网格划分 → 边界条件定义 → 求解 → 后处理
```

CAD引擎在CAE流程中扮演关键角色：

1. **几何导入**：支持多种CAD格式，保证几何精度
2. **几何修复**：修复导入过程中的几何缺陷
3. **几何简化**：移除不影响仿真精度的小特征
4. **网格准备**：提供拓扑信息支持网格生成
5. **边界条件支持**：支持面/边/点的命名选择集

### 2.2 主要CAE软件对CAD的需求

| CAE软件 | 几何需求特点 |
|---------|-------------|
| ANSYS | 支持参数化几何、命名选择集、装配体 |
| Abaqus | 几何修复、特征抑制、分区 |
| OpenFOAM | STL/网格生成、几何分解 |
| COMSOL | 参数化几何、物理场接口定义 |
| HFSS/CST | 高精度曲面、材料属性关联 |
| SimScale | 基于Web的几何处理、修复 |

## 3. CAD引擎核心要求

### 3.1 几何内核基础

多物理场仿真要求CAD引擎具备以下核心能力：

#### 3.1.1 精确的边界表示（B-Rep）

| 要求 | 说明 | 重要程度 |
|------|------|---------|
| 解析曲面支持 | 平面、柱面、球面、锥面、环面等 | ★★★★★ |
| 样条曲面支持 | NURBS/B-Spline曲面 | ★★★★★ |
| 裁剪曲面 | 支持任意边界的裁剪面 | ★★★★★ |
| 拓扑一致性 | 面与面之间的水密连接 | ★★★★★ |
| 参数域映射 | 3D曲线与曲面参数域的PCurve | ★★★★☆ |

#### 3.1.2 容差管理

| 容差类型 | 说明 | 用途 |
|---------|------|------|
| 几何容差 | 点重合判断阈值 | 处理导入数据的数值误差 |
| 拓扑容差 | 边/面的邻接容差 | 网格生成时的水密性保证 |
| 参数容差 | 参数域精度 | 曲线投影、求交计算 |

**关键要求**：
- 全局容差设置
- 实体级容差（顶点/边/面独立容差）
- 容差传播机制（布尔运算后容差更新）

#### 3.1.3 几何有效性

仿真对几何有效性要求极高：

| 检查项 | 说明 |
|-------|------|
| 水密性 | 无间隙、无重叠 |
| 法向一致性 | 相邻面法向正确朝向 |
| 边连续性 | 边的端点严格重合 |
| 面有效性 | 面积 > 0，法向有效 |
| 流形性 | 每条边恰好属于两个面（流形实体） |

### 3.2 几何修复能力

导入的CAD模型常见问题及修复需求：

| 问题类型 | 描述 | 修复方法 |
|---------|------|---------|
| 间隙 | 相邻面之间有小间隙 | 缝合、顶点合并 |
| 重叠 | 面之间存在重叠区域 | 相交处理、面裁剪 |
| 小边 | 边长度过小 | 边合并、边删除 |
| 退化面 | 面积接近零的面 | 面删除 |
| 法向错误 | 面法向朝内 | 法向翻转 |
| 自相交 | 几何自相交 | 几何重建 |

### 3.3 几何简化/去特征化

为减少网格规模，需要移除不影响仿真精度的特征：

| 简化操作 | 说明 | 对仿真的影响 |
|---------|------|-------------|
| 小孔移除 | 移除直径小于阈值的孔 | 减少局部网格密度 |
| 小圆角移除 | 将圆角替换为尖角 | 简化几何，加速网格 |
| 小倒角移除 | 将倒角替换为尖角 | 同上 |
| 凸台/凹陷移除 | 移除小特征 | 整体分析时忽略局部细节 |
| 曲面简化 | 高阶曲面降阶 | 加速求交计算 |
| 对称简化 | 利用对称性只保留部分几何 | 大幅减少计算量 |

## 4. 网格生成支持

### 4.1 网格类型

多物理场仿真涉及多种网格类型：

| 网格类型 | 适用场景 | CAD引擎支持需求 |
|---------|---------|----------------|
| 表面三角形网格 | 可视化、边界元法 | 曲面参数化、边界离散 |
| 表面四边形网格 | 结构化网格、壳分析 | 映射网格、中轴提取 |
| 四面体网格 | 非结构化体网格 | 体积网格生成、质量优化 |
| 六面体网格 | 结构化分析 | 几何分解、块结构 |
| 多面体网格 | CFD优化网格 | 拓扑感知、对偶网格 |
| 边界层网格 | CFD边界层、热边界层 | 法向偏移、局部加密 |

### 4.2 网格生成对CAD的要求

#### 4.2.1 几何离散化

| 功能 | 说明 | API需求 |
|------|------|--------|
| 曲面三角化 | 将曲面离散为三角形网格 | 可调精度、自适应细分 |
| 曲线离散化 | 将曲线离散为折线 | 弦高误差控制 |
| 参数域采样 | 在参数空间采样 | 参数域到3D映射 |
| 自适应网格 | 根据曲率自动加密 | 曲率计算、网格尺寸场 |

#### 4.2.2 网格质量控制

| 质量指标 | 说明 |
|---------|------|
| 长宽比 | 单元长宽比 |
| 偏斜度 | 单元偏离理想形状的程度 |
| 雅可比 | 单元雅可比行列式 |
| 最小/最大角度 | 单元内角范围 |

#### 4.2.3 共形网格

多物理场耦合需要共形网格（共享界面网格）：

| 要求 | 说明 |
|------|------|
| 界面印记 | 将界面几何印记到网格 |
| 一对一节点匹配 | 界面两侧网格节点对应 |
| 顶点对齐 | 界面边界顶点对齐 |

### 4.3 RCAD当前网格能力

| 功能 | RCAD状态 | 备注 |
|------|---------|------|
| 曲面三角化 | ✅ 已实现 | `triangulate` 模块 |
| 曲线离散化 | ✅ 已实现 | 弦高误差控制 |
| 自适应细分 | ✅ 已实现 | 曲率自适应 |
| 体积网格生成 | ❌ 缺失 | 需要集成 TetGen/Gmsh |
| 四面体网格 | ❌ 缺失 | 需要第三方库 |
| 六面体网格 | ❌ 缺失 | 高级功能 |
| 边界层网格 | ❌ 缺失 | CFD专用 |
| 网格质量优化 | ❌ 缺失 | 后处理优化 |

## 5. CAE前处理功能

### 5.1 几何印记（Imprinting）

将多个几何体的界面相互印记，生成共形网格拓扑：

```
几何体A ──────┐
              ├──→ 印记操作 ──→ 共形几何
几何体B ──────┘
```

| 印记功能 | 说明 | RCAD状态 |
|---------|------|---------|
| 面印记 | 将几何边界印记到面上 | ✅ `imprint_brep` |
| 边印记 | 将曲线印记到面上 | ⚠️ 部分 |
| 间隙检测 | 检测几何之间的间隙 | ✅ `detect_gaps_overlaps` |
| 共面检测 | 检测共面对 | ⚠️ 部分 |

### 5.2 命名选择集（Named Selections）

为边界条件定义提供几何分组：

| 选择集类型 | 说明 | 用途 |
|-----------|------|------|
| 面选择集 | 一组面的集合 | 压力边界、热边界 |
| 边选择集 | 一组边的集合 | 约束边界 |
| 顶点选择集 | 一组点的集合 | 点载荷 |
| 体选择集 | 一组体的集合 | 材料区域 |

**RCAD状态**：⚠️ 部分支持（有颜色分组，但缺少语义化的命名选择集API）

### 5.3 材料属性关联

| 功能 | 说明 | RCAD状态 |
|------|------|---------|
| 材料定义 | 材料属性数据结构 | ⚠️ STEP材料读取 |
| 材料分配 | 将材料关联到几何区域 | ⚠️ 部分 |
| 材料属性继承 | 装配体中的材料传递 | ❌ 缺失 |
| 多物理场材料 | 不同物理场的材料属性 | ❌ 缺失 |

### 5.4 布尔运算用于CAE

CAE前处理大量使用布尔运算：

| 操作 | 用途 | RCAD状态 |
|------|------|---------|
| 布尔减 | 创建孔洞、腔体 | ✅ 支持 |
| 布尔并 | 合并几何体 | ✅ 支持 |
| 布尔交 | 取交集 | ✅ 支持 |
| 分割 | 分割几何区域 | ⚠️ Splitter |
| 切片 | 生成截面 | ✅ `section_curves` |

## 9. RCAD功能差距与路线图

### 9.1 关键差距分析

#### 第一优先级（核心CAE能力）

| 差距 | 影响 | 工作量 |
|------|------|-------|
| 体积网格生成 | 无法进行有限元分析 | 大 |
| 布尔运算鲁棒性 | 几何处理失败率高 | 大 |
| 去特征化 | 无法简化复杂几何 | 中 |
| 命名选择集 | 边界条件定义困难 | 中 |

#### 第二优先级（专业CAE能力）

| 差距 | 影响 | 工作量 |
|------|------|-------|
| CAE网格格式导出 | 与CAE软件集成困难 | 中 |
| 装配体接触检测 | 装配体仿真效率低 | 中 |
| 流体域提取 | 无法进行CFD仿真 | 大 |
| 材料属性管理 | 多物理场材料定义困难 | 中 |

#### 第三优先级（高级CAE能力）

| 差距 | 影响 | 工作量 |
|------|------|-------|
| 六面体网格 | 结构化网格需求 | 大 |
| 边界层网格 | CFD精度受限 | 中 |
| 共享拓扑 | 多物理场耦合效率低 | 中 |
| FSI支持 | 流固耦合仿真困难 | 大 |

### 9.2 功能增强路线图

### 9.3 技术方案建议

#### 体积网格集成方案

```
方案A：集成 TetGen
  - 优点：成熟稳定、四面体网格质量高
  - 缺点：C++库、许可证限制
  - 工作量：中等

  - 优点：开源、多格式支持、功能丰富
  - 缺点：依赖较重
  - 工作量：中等

方案C：自研体积网格
  - 优点：完全可控、与几何内核深度集成
  - 缺点：开发周期长、难度大
  - 工作量：大
```

#### 去特征化实现路径

```
1. 基于尺寸过滤

2. 基于拓扑分析
   - 凸台/凹陷识别
   - 特征边界检测
   - 特征抑制/移除

3. 基于简化规则
   - 曲面降阶
   - 细节抑制
   - 对称简化
```

## 10. 总结与建议

### 10.1 关键发现

1. **几何内核能力充足**：RCAD的几何内核已具备支持多物理场仿真的大部分基础能力，包括精确的B-Rep表示、解析曲面和样条曲面支持、几何修复功能等。

2. **网格生成是最大短板**：缺少体积网格生成能力是RCAD支持多物理场仿真的最大障碍。表面网格已实现，但四面体/六面体网格需要集成第三方库或自研。

3. **布尔运算需要增强**：曲面体布尔运算的鲁棒性仍需提升，这是CAE前处理中最常用的操作之一。

4. **CAE专用功能缺失**：去特征化、命名选择集、CAE网格格式导出等专业功能尚未实现，这些是CAE工作流的关键环节。

5. **多物理场耦合支持有限**：装配体接触检测、流体域提取、共享拓扑等支持多物理场耦合的功能尚未实现。

### 10.2 优先发展建议

#### 短期（3-6个月）

1. **集成体积网格生成库**：集成 Gmsh 或 TetGen，实现四面体网格生成
2. **完善布尔运算**：提升曲面体布尔运算的鲁棒性
3. **实现命名选择集**：为边界条件定义提供几何分组API
4. **CAE格式导出**：支持 VTK、MSH 等常用CAE网格格式

#### 中期（6-12个月）

1. **去特征化功能**：实现小孔、小圆角、小特征移除
2. **装配体增强**：接触检测、干涉检查
3. **材料属性系统**：完善材料属性管理和分配
4. **网格质量优化**：网格平滑、质量改进

#### 长期（12-18个月）

1. **高级网格**：六面体网格、边界层网格
2. **多物理场支持**：流体域提取、共享拓扑
3. **CAE软件集成**：与主流CAE软件的接口

### 10.3 技术路线建议

```
优先级排序：
  1. 体积网格生成（集成 Gmsh/TetGen）
  2. 布尔运算鲁棒性提升
  3. 命名选择集与CAE格式导出
  4. 去特征化功能
  5. 装配体增强与材料系统
  6. 高级网格与多物理场耦合
```

### 10.4 结论

RCAD作为一个新兴的Rust CAD内核，在几何基础方面已经具备了支持多物理场仿真的核心能力。要成为真正可用的CAE前处理几何引擎，需要在以下方向持续投入：

1. **补齐网格生成能力**：这是最关键的缺失功能
2. **提升算法鲁棒性**：特别是布尔运算和几何修复
3. **完善CAE专用功能**：去特征化、命名选择集、CAE格式支持
4. **增强多物理场支持**：装配体处理、耦合界面支持

按上述路线图发展，预计在12-18个月内，RCAD可以具备支持基础多物理场仿真（FEA/CFD）的能力。
